One-line office joke for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty ($5 prize pool, top 10). The program writes a single joke about office life — blocking the day for focus time, and getting a meeting about the focus time itself — to `entry.txt`. The joke is the winner of a 6-finalist head-to-head tournament judged with the competition's own judge brief: undefeated (4 wins, 1 level game).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
